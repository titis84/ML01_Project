# Lightweight Speech-to-Text Pipeline

## Overview

This project implements a lightweight Automatic Speech Recognition (ASR) pipeline for converting audio files into text.

The project studies the impact of audio preprocessing and LLM-based post-processing on transcription quality.

Three audio configurations are compared:

- *Original audio*
- *Denoised audio*
- *Denoised + Voice Activity Detection (VAD) audio*

The audio is transcribed using *Whisper Tiny* and can then be post-processed using *Google Gemini*.

## Objective

The objective is to evaluate how audio preprocessing and LLM-based post-processing affect ASR performance.

The project evaluates:

- the impact of noise reduction;
- the impact of Voice Activity Detection (VAD);
- Whisper transcription before and after Gemini correction;
- transcription quality using Word Error Rate (WER);
- Whisper inference time.

Whisper Tiny was selected as a lightweight model providing satisfactory results for the project's use case, while requiring fewer computational resources than larger Whisper models.

## Audio Processing

The preprocessing stage generates different versions of the audio:

- *Original* — original audio without preprocessing.
- *Denoised* — noise reduction using noisereduce.
- *Denoised + VAD* — denoising followed by activity-based segmentation to remove non-speech intervals.

Audio is converted to mono and resampled to 16 kHz before processing.

### Voice Activity Detection

Voice Activity Detection (VAD) is used to identify segments containing audio activity and remove non-speech intervals such as silence.

The detected segments are then concatenated and saved as a new audio file.

## Speech Recognition

Each audio configuration is transcribed using openai/whisper-tiny through Hugging Face Transformers.

The original Whisper transcription and inference time are saved for each file.

Whisper Tiny was selected as a lightweight model providing satisfactory results for the project's use case.

## Gemini Post-Processing

Google Gemini is used to correct obvious transcription errors while preserving the original meaning.

The correction is designed to:

- correct obvious transcription errors;
- correct spelling mistakes and homophones when appropriate;
- preserve the original meaning;
- avoid adding information;
- avoid rewriting sentences that are already correct.

Two outputs are kept:

- *Whisper Transcription* — the original output generated by Whisper.
- *Gemini-Corrected Transcription* — the output after Gemini correction.

## Evaluation

The different configurations are evaluated using *Word Error Rate (WER)* by comparing generated transcriptions with reference transcriptions.

Whisper inference time is also recorded.

The evaluation focuses on the impact of:

- audio preprocessing;
- denoising;
- Voice Activity Detection;
- Gemini post-processing.
